# Trust Platform

Plataforma de verificación de llamadas y mensajes con enfoque en identidad verificada, motivo de contacto y scoring de riesgo.

## Stack inicial
- Backend: Go
- Frontend: React + TypeScript
- Base de datos: PostgreSQL
- Cache: Redis

## Objetivo del MVP
- Empresas verificadas
- Motivos de llamada
- API simple de verificación
- Dashboard interno
- Scoring básico por reglas
